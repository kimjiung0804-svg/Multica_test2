# Enable Design System — website clone

Next.js + Tailwind CSS + shadcn/ui recreation of
[enabledesign.io](https://www.enabledesign.io/).

## Pages

| Route | Content |
|---|---|
| `/` | Home hero, services, ML-EDA research, CTA |
| `/solution` | Four service offerings + ecosystem CTA |
| `/product` | IO Planner, Pad Placer, LDRC, Wafer Test Utility |
| `/company` | About, story, partners |
| `/news` | News listing + article |
| `/contact` | Contact form, phone/fax/email, visit directions |

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Notes

- Brand colors follow the live Wix theme (primary `#0088CB`, navy `#0a1628`).
